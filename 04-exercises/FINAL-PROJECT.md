# 期末專案 — 在 PVE 上部署高可用 Kubernetes 叢集

> 評量：驗證學員是否具備獨立建構、部署與維運的能力。

## 任務
在 PVE 9.x 上，獨立完成一套 **3 控制平面 + 2–3 worker** 的高可用 Kubernetes 叢集，並部署一個具 **持久儲存** 與 **自動擴展** 的範例應用。

## 交付項目
1. **架構文件**：節點配置表、網段規畫、儲存規畫（為何用 Ceph/local）。
2. **安裝紀錄**：kubeadm 安裝過程與 `kubectl get nodes -o wide`、`kubectl get pods -A` 輸出。
3. **高可用驗證**：停掉一台控制平面 VM，證明叢集持續可用。
4. **儲存/擴展**：部署 StatefulSet（含 PVC）與啟用 HPA（依 CPU 擴展）的無狀態應用。
5. **備份**：執行過一次 etcd 備份並產出備份檔狀態。

## 評分要點
- 架構正確性（分散節點、共用儲存、LB）。
- 安裝可重現、指令正確。
- 能說明運作原理（控制平面/worker/物件關係）。
- 針對故障能除錯與恢復。

## 建議時程
- 第 1–2 小時：架構＋VM 建置（對照 Class 4）。
- 第 2–4 小時：kubeadm 安裝＋CNI＋worker 加入（對照 Class 5）。
- 第 4–6 小時：儲存/HPA/監控/備份（對照 Class 6）。
- 最後 1 小時：HA 故障演練與簡報。
